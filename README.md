# glowing-octo-enigma

A simple, responsive calculator built with HTML, CSS, and vanilla JavaScript.

## Features

- Addition, subtraction, multiplication, and division
- Percentage and sign-toggle controls
- Keyboard support
- Responsive layout and accessible button labels
- Handles division by zero

## Run locally

Open `index.html` in a web browser. No build tools or dependencies are required.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `0`–`9` | Enter a digit |
| `.` | Decimal point |
| `+`, `-`, `*`, `/` | Choose an operation |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete the last digit |
| `Escape` | Clear the calculator |
